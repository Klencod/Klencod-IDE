Klencod IDE

A Powerful Android Development Environment — Right in Your Pocket.

Klencod IDE is an integrated development environment for Android devices, designed to help you create application projects, write and edit code, manage files, and build applications directly from your phone.

With its advanced code editor, local and cloud build capabilities, GitHub integration, and advanced AI tools, Klencod IDE provides a flexible and integrated development experience on Android devices.

Features

Advanced Code Editor

- Support for multiple programming languages.
- Syntax highlighting and smart code completion.
- Open multiple files in separate tabs.
- Independent undo and redo history for each file.
- Search, replace, and jump to a specific line.
- Customizable themes, colors, and font sizes.
- Smooth editing of large files containing up to 100,000 lines.
- Edit code without an internet connection.

Project and File Management

- Integrated file manager.
- Create, rename, import, and manage files and folders.
- Import projects from ZIP archives.
- Export complete projects as ZIP archives.
- View images, videos, and audio files.

Local and Cloud Builds

- Local Android application builds using Klencod Build Engine.
- Local build support for Java and Kotlin projects.
- Cloud builds through GitHub Actions.
- Cloud build support for Flutter, Java, Kotlin, and React Native projects.
- Monitor build progress and background operations.
- Generate and download APK files.

GitHub and Git Integration

- Sign in to GitHub and manage multiple accounts.
- Create repositories and link them to projects.
- Publish projects to GitHub.
- Manage local Git changes.
- Perform Commit, Push, and Pull operations.
- Git LFS support for large files.

Built-App Library

- Keep a record of generated APK files.
- Export APK files to a folder of your choice.
- Access previously built applications without rebuilding them.

Build Logs and Logcat

- Detailed build logs.
- Clear highlighting of errors and warnings.
- Search and filter logs.
- Navigate to related source-code locations when information is available.
- Copy and export logs.
- Monitor application runtime logs using Logcat.

Signing Key Management

- Import and manage Android signing keys.
- Store multiple signing keys.
- Select a default signing key.
- Use the same personal signing identity for both Debug and Release builds.

Build Engine

Klencod IDE integrates with Klencod Build Engine, a separate Android application responsible for performing local builds of Android projects.

The IDE and Build Engine operate as independent applications and communicate with each other to provide an integrated development experience.

Project Status

Klencod IDE is actively developed, with ongoing improvements to the code editor, project management, build system, and overall user experience.
